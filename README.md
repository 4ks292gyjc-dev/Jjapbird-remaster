# 짭새의 모험 — 리마스터

카메라(몸동작)·키보드·터치로 조작하는 3D 수직 등반 게임 「짭새의 모험」의 리마스터판입니다.
원본: [jjapbird-perf](https://github.com/4ks292gyjc-dev/jjapbird-perf)

## 바뀐 점
- **디자인 "야간 순찰"**: 남색 밤하늘 + 경광등 빨강·파랑 빛 + 경찰 배지 금색
  - 메뉴: 사건 파일 배지, 굵은 금색 제목, 난이도 색 번호 배지가 붙은 단계 카드
  - 게임 화면: 어두운 유리 패널(버튼·기록), 금색 고도 막대, 체력 바 그라데이션
  - 창(일시정지·클리어·기록): 따뜻한 종이색 패널, 굵은 제목
- **고화질 그래픽 설정**(일시정지 > 설정): 해상도 2배까지·그림자 2배. 모든 기기 기본 켬
- 데스크탑·폰·패드(세로·가로) 모든 화면에서 메뉴 버튼이 첫 화면에 들어오도록 정리
- 실사 재질 32가지: [ambientCG](https://ambientcg.com) CC0 텍스처의 색·노멀(요철)·거칠기·금속·AO 지도를 모두 사용 (목록: `tools/atlas.py`)
